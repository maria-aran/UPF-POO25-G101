## Report Lab 4

This lab consisted of implementing linear regression with stochastic gradient descent with support for standardized datasets.  Compared to the previous code, there is a clear improvement in the relations and the functionality. For instance, by making Dataset abstract and RawDataset and StandardizedDataset its subclasses. We can clearly see abstraction with the Algorithm class, which has concrete implementations for GradientDescent and StochasticGradientDescent with minibatch sampling. We can see the same pattern with the Predictor abstract class, which has LinearRegressionPredictor and LogisticRegressionPredictor as subclasses for different regression types.

The code works the following way. Dataset defines the common interface for all datasets, so the methods transform and output become abstract. RawDataset and StandardizedDataset override both methods with their corresponding ways. This way both methods inherit from Dataset but are not abstract.

The StochasticGradientDescent has a main method stochasticGradient. It creates a mini batch by randomly selecting small subsets of data for each update.

The regression predictors have an abstract class called Predictor. With two abstract methods, predict and computeGradient, the classes LogisticRegressionPredictor and LinearRegressionPredictor will then override in their corresponding way. The logistic prediction will have an auxiliary function, the sigmoid function. And will override the predict method computing the dot product with parameters and the augmented input, just like linear regression. And then apply the sigmoid function. The gradient will be the same form as linear regression, but with a different prediction, it uses a sigmoid linear regression instead of a linear function.
