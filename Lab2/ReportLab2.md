#Lab 2: Implementing a class diagram 

The aim of this project was to manage relations in a more practical way. The primary functionality of this project is to store multiple records in a Dataset, where various operations, such as computing the mean and standard deviation, can be performed. These calculations are later used to standardize the Dataset. I believe that making StandarizedDataset inherit from Dataset is the most important part of this practice, as it clearly shows how the inheritance relation helps us reuse operations and necessary attributes. This can also be helpful in the future, as knowing how to standardize datasets prevents algorithms from being biased toward features with larger values. At the end, the Normalized Dataset Class was added. Showing another inheritance relationship, such as the Standarized one.

The code works the following way. We see that the Dataset has as attributes the dimension and the List of records. Since there’s a class that inherits from this one, they cannot be private, they need to be protected, so attributes are accessible from the subclass. The Dataset Class also has the corresponding getters. And other methods are: Add records, which adds a new record to the dataset only if it has the corresponding dimension, in order to avoid inconsistency and errors. And meanInput, meanOutput, which perform the mean. And stdInput and stdOutput, which compute the standard deviation for both input and output. Finally, we have the Standardized Dataset method. I believe it is the most interesting and engaging. This method first computes the statistics for all input and output on the dataset, using the previously described functions. These statistics will later be necessary to transform each record into a standardized form. Then, it creates a new instance of the subclass StandardizedDataset. This is the reason I believe this is the most interesting step, it clearly demonstrates how useful inheritance is. After, we add all transformed records. So it returns a Standardized Dataset. 

The Class StandardizedDataset has as attributes the means and standard deviations for both the input and output. The constructor is called on the superclass and, as a remarkable thing, uses the keyword “super” to get the dimension from the Dataset class, since the method belongs to the superclass. It also has the transform method, used in the Dataset also. This will standardize the input and output. Making the mean 0 and the standard deviation 1. It will return a Record instance with these new values. As explained earlier, but in order to highlight, we can clearly see how these functions are used in the method StandardizedDataset in Dataset. So, without the inheritance, this will not only be more difficult but also less optimized. The project also has a TestDataset Class, but it is a mechanical process. Check that the values computed by the code are equal to the manually computed ones, and print them.

The newly added Class, Normalized Dataset works the following way. The class inherits from Dataset, as it is clearly a specialized case of a dataset. This way, there's no need of reimplementing the methods and attributes from Dataset. As new attributes, we have the same ones as in StandardizedDataset. The constructor also works in the same way. The transform method works by applying a formula to make the maximum value one and the minimum 0. Basically changes the range of values from zero to one. It also has the respective getters. The transformed method is then called on the Dataset class. Again, showing the relation between both classes. Similitudes between this class and the StandarizedDataset Class are clear. Both applying their corresponding formula in a quite similar way.

We can see various relationships through the code. The Dataset aggregates Records. Which we can clearly see since the Dataset stores diverse Records. On the other hand, Vector is only used for calculations but not stored, so as seen in theory, there is a clear relation of dependency. But the most significant relation is inheritance. Clearly, StandarizedDataset is a type of Dataset, a specialized version. This relation makes programming easier and more efficient, avoiding duplication. All instance members from the superclass, Dataset, will be part of the subclass. There’s also no need to define methods and attributes, since all are reused, like meanInput() and stdInput(). It helps with consistency too, it is enough to make a change or improvement in the superclass, the subclass automatically benefits from it, which also makes it easier to expand in future classes. NormalizedDataset adds a new relation of inheritance that works in parallel with StandardizedDataset, both specializing the Dataset class. Showing polymorphism, both classes have their type of method transform. Many classes that transformed in an original way the dataset could be implemented, and the Dataset wouldn't have to be changed, we would just need to add the methods.
