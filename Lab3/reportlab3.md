The goal of this project was to compute several classes where linear regression models could be trained using more than one method, such as gradient descent and the Moore–Penrose pseudo-inverse.

The class model works as a container for the parameter vector (θ). It has a class usuals methods. Additionally, it also has 'predict' which computes the dot product between the model's params and the provided augmented input vector. And 'update' which executes a single step of gradient descent.

Then, SupervisedLearner Class does the following. Again, it has its basic methods. And, additionally, the 'solve' method, which calls the algorithm solve method. Showing clear composition. It also has a 'predict' method. It takes a raw input vector and uses the trained model to predict an output value. It also contains the solveWithPseudoInverse method. Which I will explain later.

Finally, we have the Algorithm class. Which has a gradient method. It computes the error of the current methods and sees how to adjust the parameters. Basically, The gradient points in the direction that would INCREASE error, so we subtract it during updates to DECREASE error. This method is called by 'solve', the other method in this class. This method checks how 'wrong' the current model is with the gradient method, as explained previously. So, after, we update the model until the model is barely improving.

The additional method, 'solveWithPseudoInverse' that is found on SupervisedLearner finds the mathematically optimal solution in one step instead of iterating like the gradient descent. It first creates a matrix where each row is one training example, copying each augmented input vector into a row of the matrix. Then, it creates a column vector of all output values. So, on the matrix we have the data, and the desired output, in order to now find a pattern to follow. Then, it computes the Moore-Penrose pseudo-inverse, using single value decomposition. Then, it makes matrix multiplication, which gives the exact mathematical solution that minimizes error. Finally, it converts everything back to a vector.
